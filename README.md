# PreOrderAni18

Brief Overview of the System;

  PreOrderAni is a pre-ordering platform that connects smallholder farmers directly with consumers, without middlemen. Farmers post crops they are about to harvest, with the crop, quantity, price, harvest date and location, so demand is visible before harvest day. Consumers browse and filter these upcoming harvests by crop and location, then reserve the quantity they want. Each reservation starts as pending, and the farmer confirms it. Farmers can see how much of their harvest is already reserved. When harvest day arrives, the farmer marks the harvest ready, and consumers see this in their reservations and arrange pickup with the farmer. Consumers can cancel a reservation before the harvest is ready, and the farmer closes the harvest as completed or cancelled. The goal is to help farmers plant with certainty instead of hope, which means less spoilage and more income. Consumers get fair prices straight from the source.
